# 톡톡! 행동기록장 v.2

기존 톡톡! 행동기록장(저장소 루트, toktok-record.vercel.app)에서 **AI 심화 분석(제미나이) 기능만 뺀** 버전입니다.

- 빠른 기록, ABC 기록, 규칙 기반 행동 리포트, PDF 저장, 구글 시트 연결은 그대로입니다.
- 외부 AI·API로 데이터를 보내지 않으므로 서버 함수나 API 키가 필요 없습니다.
- 이 폴더(v2)의 index.html 하나로 동작하며, Vercel 프로젝트 toktok-record-v2 가 이 폴더를 루트로 배포합니다.
- 주소가 다르면 브라우저 저장소도 따로입니다. 기기에만 저장한 기록은 기존 주소에서 [설정 → 백업 파일(JSON) 받기] 후, v.2에서 [백업 복원]으로 옮기세요.
